# esc_measurements — драйвер вимірювань (напруга + струм)

Драйвер для аналогових вимірювань напруги батареї та струму двигуна через АЦП (ADC1) ESP32. Значення передаються на телефон по Bluetooth у зарезервовані байти телеметрії `batt_voltage` / `batt_current`.

## Апаратне підключення

| Канал   | GPIO | Джерело                                   |
|---------|------|--------------------------------------------|
| Напруга | 35   | дільник R1=100k / R2=12k (K ≈ 0.106)      |
| Струм   | 34   | ACHS-7125 (±50 A) через вихідний дільник 1.5k/10k |
| HX711 SCK  | 22 | тензодатчик (тяга)                       |
| HX711 DOUT | 23 | тензодатчик (тяга)                       |

- Датчик струму ACHS-7125 живиться від стабілізованих 5 В.
- Дані з датчика знижуються дільником 1.5k/10k до рівня, безпечного для входу GPIO34.

## Калібрування (мультиметр)

Усі коефіцієнти задаються у `esc_measurements.h`:

| Константа                    | Опис                                          |
|------------------------------|-----------------------------------------------|
| `MEAS_DIVIDER_K`             | фактичний коефіцієнт дільника напруги         |
| `MEAS_VOLTAGE_OFFSET_V`      | постійний зсув напруги (В)                    |
| `MEAS_VZERO_MV`              | вихід датчика струму при 0 А (мВ)             |
| `MEAS_SENS_MV_PER_A`         | чутливість датчика струму (мВ/А)              |
| `MEAS_CURRENT_ADC_OFFSET_MV` | зсув каналу АЦП (канал читає вище реального)  |

Калібрування напруги виконується за двома точками блока живлення (напр. 20 В і 25 В) мультиметром; струму — за 0 А та відомим струмом (напр. 1 А) у режимі постійного струму.

## Шумозахист

- Усереднення `MEAS_CURRENT_SAMPLES` (256) семплів на один вимір.
- EMA-фільтр (`MEAS_EMA_ALPHA` = 0.4) між вимірами для додаткового згладжування.
- Клепінг від'ємного струму до 0 (стенд тяги — односторонній струм).

## Використання

```c
#include "esc_measurements.h"

void app_main(void)
{
    esc_measurements_init();                 // один раз при старті

    float volts = 0.0f;
    float amps  = 0.0f;

    if (esc_measurements_read_voltage(&volts) == ESP_OK)
        ESP_LOGI("APP", "V = %.2f", volts);  // з урахуванням дільника

    if (esc_measurements_read_current(&amps) == ESP_OK)
        ESP_LOGI("APP", "I = %.2f", amps);   // з урахуванням калібровки
}
```

## Інтеграція з телеметрією

У `bluetooth_spp.c` (задача `bt_telemetry_task`) значення напруги та струму читаються драйвером і кладуться у кадр телеметрії:

- `raw.batt_voltage` — напруга, 1 LSB = 0.1 В;
- `raw.batt_current` — струм, 1 LSB = 0.1 А.

Телефон показує напругу в `l_voltage_2`, струм — в `l_voltage_3`.

## Залежності

Компоненти ESP-IDF: `esp_adc` (oneshot + line-fitting калібровка). Додано у `REQUIRES` у `main/CMakeLists.txt`.
