# 🔌 Повна схема підключення ESP_Motor_test

> MCU: ESP32 · SDK: ESP-IDF v5.x. Усі призначення GPIO взяті з коду
> (`main/esc_pwm.h`, `main/esc_measurements.h`, `main/dshot_rmt.c`,
> `PROJECT_STRUCTURE.md`).

## Призначення виводів ESP32

| Вивід ESP32 | Призначення | Куди йде |
|---|---|---|
| GPIO18 | Сигнал ESC (PWM / DShot) | до SIG контролера мотора |
| GPIO34 (ADC1_CH6, вхід тільки) | Струм | вихід ACHS-7125 (через дільник 1.5k/10k) |
| GPIO35 (ADC1_CH7, вхід тільки) | Напруга батареї | вузол дільника 100k/12k |
| GPIO22 | HX711 SCK | годинник тензодатчика |
| GPIO23 | HX711 DOUT | дані тензодатчика |
| GPIO5 | DEBUG (опціонально) | осцилограф / лог. аналізатор |
| GND | Земля | загальна з батареєю / ESC / датчиками |
| 5V / VIN | Живлення плати | вихід XL4015 |
| 3V3 | Живлення логіки 3.3В | HX711 (логіка, див. примітку) |

## XL4015 (понижуючий DC-DC)

```
Батарея (LiPo 2–4S) ──► [IN+] XL4015 [IN-]
                          │
                    (крутиш R-підстроєчник → OUT = 5.0В)
                          │
                    [OUT+] ──► 5V ESP32 (VIN/5V)
                    [OUT-] ──► GND (загальна шина)
```

Вихід XL4015 5В живить: ESP32 (через його вбудований 3.3В-стаб),
ACHS-7125 (VCC), і (через 3.3В) HX711.

## Повна схема

```
                          ┌───────────────────────────────┐
   Батарея + ─────────────┤ IP+                        OUT├─┐
   (LiPo)                 │ ACHS-7125 (±50A)             │ │
   Батарея ─┐             │ IP-                       VCC├─┼─► 5V (XL4015 OUT)
            │             │                          GND ├─┘
            │             └───────┬──────────────────────┘
            │                     │  OUT (аналог, ~1.7В)
            │                     │
            │               [1.5k]│───┬──► GPIO34 (ESP32)
            │                     │   [10k]
            │                     │    │
            │                    GND  GND
            │
            │        ┌──[100k]─── вузол ──► GPIO35 (ESP32)
            ├────────┤
            │        └──[12k]─── GND
            │
            │   ┌──────────── ESP32 ────────────┐
            └───┤ GND          GPIO18 ─┐        │
                │              GPIO22  │        │
                │              GPIO23  │        │
                │              GPIO5 (dbg)       │
                │              3V3 ──┐          │
                │              5V/VIN◄┼─ XL4015 │
                └────────────────────┼──────────┘
                                     │
   ESC (контролер мотора) ◄─────────┘ SIG
       │          │
   ESC + ─────────┘ (живлення мотора, від батареї/ACHS)
   ESC GND ───────► загальна GND
       │
     МОТОР

   HX711 модуль:
     VCC ─► 3.3V (ESP32)   ← або 5V + резистивний дільник на DOUT!
     GND ─► GND
     SCK ─► GPIO22
     DOUT─► GPIO23
     (HX711 E+ E- A+ A- → тензодатчик/вага)
```

## Важливі застереження

- **GPIO34/35 — вхідні тільки (input-only)**, не використовуй як виходи.
- **ACHS-7125** ставиться *послідовно* в лінію живлення мотора
  (IP+ → IP−), а не паралельно. Живи його стабільними 5В.
- **HX711 логіка:** якщо живиш HX711 від 5В, його DOUT може видавати 5В
  на GPIO23 (небезпечно для ESP32 3.3В). Безпечніше живити HX711 від
  **3.3В** ESP32, або поставити дільник на DOUT. DOUT зазвичай потребує
  підтяжки до VCC.
- **Загальна земля (GND)** обов'язково з'єднана між батареєю, XL4015,
  ESP32, ESC і датчиками — інакше виміри напруги/струму та сигнал ESC
  будуть «плавати».
- **XL4015** має лише понижуючий режим: вхід має бути вищим за вихід
  (батарея ≥ ~6В для стабільних 5В).

## Калібрування (див. `esc_measurements.h`)

| Константа | Значення за замовчуванням | Опис |
|---|---|---|
| `MEAS_DIVIDER_K` | 0.1060 | коефіцієнт дільника напруги |
| `MEAS_VOLTAGE_OFFSET_V` | 0.4 | зсув напруги (В) |
| `MEAS_VZERO_MV` | 1683 | вихід датчика струму при 0 А |
| `MEAS_SENS_MV_PER_A` | 28.0 | чутливість струму (мВ/А) |
| `MEAS_CURRENT_ADC_OFFSET_MV` | 32.0 | зсув каналу ADC (мВ) |
| `HX711_SCALE_COUNTS_PER_G` | 0.0 | 0 = сирий режим (не калібровано) |
